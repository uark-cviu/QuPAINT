# Example micrographs

Optical micrographs of exfoliated 2D material flakes on SiO₂/Si, provided so you can run
`inference.py` and `demo.py` without any data download.

They are a small sample only. The full training and demo data is on
[Google Drive](https://drive.google.com/drive/folders/1MxII8ajBS2mX3LHPo0pN4aKZzgmrXdJx?usp=sharing);
QF-Bench is released separately (see the main README).
